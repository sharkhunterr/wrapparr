# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-03-28

### Features

- Full recap system with 26+ slide types
- 15 visual themes with dynamic effects (Glass Dark, Neon Retro, Matrix, Pirate, etc.)
- Per-theme toggleable effects (sabres laser, pluie matrix, guirlande Stranger Things, etc.)
- Palette de couleurs associees par theme
- Onboarding slide with interactive settings
- Year-over-year comparison with inline badges
- Community slides (rankings, activity, genres)
- Music system (YouTube download, per-section tracks)
- Admin panel (slides, themes, services, users, config)
- SSO authentication (ephemeral code exchange)
- Responsive design (phone, tablet, desktop)
- Share button + fullscreen + navigation
- 7 service integrations (Tautulli, Jellyfin, TMDB, ROMM, Audiobookshelf, Komga, Booklore)

### Themes

- Glass Dark (default), Neon Retro, Cinema Classic, Weyland-Yutani, Pirate
- Arcade 8-bit, Matrix, Upside Down, Galaxie lointaine, Cinema Muet
- Sin City, Abysse, VHS 90s, Comic Book, Tableau Noir, Noel
