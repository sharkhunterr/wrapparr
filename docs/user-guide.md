# User Guide

## Recap
Navigate to your recap at the root URL. Use arrows or swipe to navigate between slides.

## Themes
15+ visual themes available. Change theme via the sun icon in the top-right bar, or on the onboarding slide.

## Comparison
Toggle year-over-year comparison via the bar chart icon in the top-right bar.

## Admin
Access the admin panel at `/admin` to configure services, slides, themes, and users.
